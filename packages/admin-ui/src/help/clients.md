Who can connect to the MCP endpoints of this server.

## Bearer tokens

A client sends a bearer token with each request. The token acts for the user who owns it, within the role of that user.

## OAuth clients

OAuth clients sign in through this server with a portal account. Register a client here when dynamic registration is off.

## OAuth grants

A grant is the consent that a user gave to an OAuth client. Revoke it to end the access of that client.
