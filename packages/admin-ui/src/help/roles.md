Admins do all administration and set the levels of each endpoint. Each other role gets the endpoints that you pick here.

## Endpoints of a role

A role reaches at most the levels that you set for it on the Access page of each endpoint. New endpoints and new groups start at **None** for each role.

With **See other endpoints**, users see the other endpoints by name and description, without access.

## Switches on an endpoint

- **Set personal levels**: users set personal levels for their own calls on this endpoint, up to the most the role allows.
- **Own pre-approval rules**: users add pre-approval rules on this endpoint that apply only to their own calls.
- **See endpoint status**: users see the health, plugin and sync state of the endpoint, and each operation, also the ones at None.
